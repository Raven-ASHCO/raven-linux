# Contributing

Thank you for helping. Raven's rules are the same in every repository; the full version is
`core/CONTRIBUTING.md` (in the `raven-core` submodule).

- **Security problems:** never in a public issue. Write to security@raven-messager.com
  ([SECURITY.md](SECURITY.md)).
- **Bugs:** open an issue with the commit you tested, your operating system and version, whether
  it was a debug or release build, the steps, and what you expected.
- **Changes:** fork, branch, add or update tests, run this repository's build and tests (see
  [README.md](README.md)), and open a pull request that says what changed and why. Open an issue
  first for larger changes.
- **Engine, protocol or shared texts:** those changes belong in `raven-core` (`core/`), not here.
- **New dependencies** need a reason and an exact version. No personal data in code, tests or docs
  (use sample names and documentation addresses). English only.
